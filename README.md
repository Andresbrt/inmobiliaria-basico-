# Grupo AAA S.A.S — Propiedades Exclusivas Frente al Mar

Landing page inmobiliaria boutique de alta gama enfocada en residencias, villas de lujo y penthouses frente al océano.

## 🚀 Características
- **Diseño Moderno & Responsivo**: Maquetación adaptativa con tipografía Poppins & Inter.
- **Catálogo Interactivo**: Filtrado dinámico de propiedades por tipo, precio y ubicación.
- **Mapa Costero Interactivo**: Integración con Leaflet.js para explorar ubicaciones de los proyectos.
- **Calculadora Financiera**: Herramienta interactiva para proyectar cuotas y créditos hipotecarios.
- **Canales de Contacto Directo**: Formularios validados y enlaces directos a WhatsApp.

## 📁 Estructura del Proyecto
```
├── index.html       # Estructura semántica principal
├── styles.css       # Estilos personalizados, diseño responsivo y animaciones
├── app.js           # Lógica interactiva (filtros, mapa, calculadora, sliders)
└── .gitignore       # Reglas de exclusión de Git
```

## 💻 Visualización Local
Abre directamente `index.html` en tu navegador web preferido o usa una extensión como Live Server en VS Code.
